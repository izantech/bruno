# @usebruno/ios

iOS host package for Bruno, built on Capacitor 8 with Swift Package Manager.

## Status

Scaffold only. The native iOS project (`ios/App/`) is generated by `npx cap add ios`
and is not included in the repository until that step is run on an Xcode 26 host.
No native plugins are wired in this batch; plugin interfaces arrive in later batches.

## One-time setup (requires Xcode 26)

Run the following from the repository root after cloning:

```sh
npm i
```

Then, from this directory (`packages/bruno-ios`):

```sh
npx cap add ios
```

This generates `ios/App/` with the Xcode project. Open `ios/App/App.xcworkspace`
in Xcode 26 to build and run.

## Daily development flow

From the repo root, start rsbuild and get the live-reload URL:

```sh
npm run dev:ios
```

This starts the rsbuild dev server and prints the local URL. Set `BRUNO_DEV_PORT`
to that port value, then launch the simulator from Xcode or run:

```sh
npx cap run ios
```

from `packages/bruno-ios`. The app will load from the rsbuild dev server.

## Static build

```sh
npm run build:ios
```

This runs `build:web` (rsbuild production build), copies the output to `www/`,
and prints a reminder to run `npx cap sync ios` from `packages/bruno-ios`
(requires Xcode installed).

## File layout

```
packages/bruno-ios/
  capacitor.config.ts   Capacitor configuration
  src/                  TypeScript plugin definitions (stub in Batch 0)
  scripts/
    copy-web.js         Copies bruno-app/dist into www/
  www/                  Generated — web bundle (gitignored)
  ios/App/              Generated by `npx cap add ios` (gitignored until created)
```
